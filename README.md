# ⚡ Cognify AI Chatbot

A professional, elegant AI Chatbot built with **React.js**, **Framer Motion**, and **Express.js (OpenAI API)** – designed for modern portfolios and production integration.



---

## ✨ **Features**

✅ AI-powered responses using OpenAI API  
✅ Beautiful, minimal UI with smooth Framer Motion animations  
✅ Responsive design for all devices  
✅ Professional glassmorphism and card UI  
✅ Modular and clean code structure



## 🚀 **Tech Stack**

- **Frontend:** React.js, Framer Motion, React Icons, CSS Modules
- **Backend:** Express.js, Node.js, OpenAI API
- **Deployment:** Vercel (frontend), Render or Railway (backend)
